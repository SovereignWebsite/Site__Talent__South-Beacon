# south-beacon.b: learnings

- Public git history keeps whatever is pushed first, so profile wording is fixed before the first push, never after.
- A quoted instruction can leak what the page hides: a code comment once gave away the candidate's gender. Comments and commit messages get the same anonymity check as the page.
- Fixed-length redaction bars hide both the value and its length.
- Every HTML page needs its link-preview tags, or the site's share check stops the deploy.
- Org apply can lag by hours; when asked, add seed files by hand from the Factory seed, and it will leave them alone.
