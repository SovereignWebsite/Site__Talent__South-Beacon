# South Beacon: designs

An anonymised talent profile. The code name is the brand; there is no photo, name, employer, date, product or outbound link.

## Concept

- Idea: a discreet executive profile that reads as complete, not as a CV with gaps.
- Centre: the code name as a wordmark, with one drawn motif (a beacon) in place of a portrait.
- Focus: what the candidate has led, in outcomes, with nothing that identifies them.
- Main action: Request an introduction, on the first screen of every design and again at the end. It opens the sealed form at /introduction/ (built by feedback.b).

## The five

1. The Brief (home): a confidential one-pager, two columns on desktop, prints to one page.
2. The Beacon: dark, a beacon with a soft sweep (still under reduced motion), achievements as signals.
3. The Dossier: a plain folder cover with the code name, the profile on index cards.
4. The Scorecard: capabilities as chips, achievements as tiles, a fit checklist that stays in the browser.
5. The Letter: the same facts as a first-person letter to the hiring board, signed South Beacon (Dinis's choice, 21 November 2026). It adds nothing the profile does not say.

All five carry the same words. The wording was softened after security.b's re-identification review (025) and approved by Dinis on 21 November 2026.
