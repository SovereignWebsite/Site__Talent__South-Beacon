# Site__Talent__South-Beacon
south-beacon.talent.sovereignweb.site: An anonymised profile of a senior technology and security leader. Introductions through the talent agent.

## Rebuilding the profile pages

The five designs and /designs/ are generated from one content source, so every design carries the same words: edit the text in `src/profile.mjs`, then run `node src/profile.mjs`. The introduction form at `site/introduction/` is feedback.b's and is not regenerated.

What the owner can do on this site, without an agent: docs/owner.md.
